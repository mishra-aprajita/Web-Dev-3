Unit 3 – MongoDB: Quick Revision Notes

1. Basic Terms
Data → Raw facts/information.
Database → Organized collection of data.
DBMS → Software used to manage databases and perform CRUD.
Data Structure → Organizes data for efficient use.
Algorithm → Step-by-step procedure to solve a problem.


2. Types of Database

Relational Database (SQL)

Data → Tables
Tables → Rows + Columns
Examples: MySQL, PostgreSQL

Non-Relational Database (NoSQL)

Not based on traditional tables.
Flexible structure.
Example: MongoDB


3. MongoDB
MongoDB = NoSQL + Document-oriented database
Stores data as documents.
Documents are grouped into collections.
Uses BSON (Binary JSON) internally.
Has a flexible schema.

Structure:
Database → Collection → Document → Field


4. SQL vs MongoDB
SQL	MongoDB
Table	Collection
Row	Document
Column	Field
Primary Key	_id

5. MongoDB Tools
mongosh → CLI/command-line tool.
MongoDB Compass → GUI/visual tool.
MongoDB Community Server → Runs the MongoDB database server.


6. Basic Commands
mongosh             → Open MongoDB Shell
show dbs            → Show databases
use college         → Select database
db                  → Show current database
show collections    → Show collections


7. CRUD

C – Create

insertOne() → insert one
insertMany() → insert multiple

R – Read

findOne() → find one
find() → find multiple

U – Update

updateOne() → update one
updateMany() → update multiple

D – Delete

deleteOne() → delete one
deleteMany() → delete multiple


8. Must Remember for Viva
MongoDB is NoSQL.
MongoDB stores documents, not rows.
Collection ≈ Table
Document ≈ Row
Field ≈ Column
_id = unique identifier
BSON = Binary JSON
mongosh = CLI
Compass = GUI
Default MongoDB port = 27017
CRUD = Create, Read, Update, Delete
MongoDB has a flexible schema.
