---Types of Authentication---
1.Password-Based Authentication: Uses a username/email and password to verify a user's identity.
2.Token-Based Authentication: Uses a token, such as JWT, to authenticate users and 
provide access to protected resources.
3 OTP-Based Authentication: Uses a One-Time Password sent to a registered mobile
 number or email for verification.
4 Biometric Authentication: Uses fingerprints, facial recognition, or iris scans to
 verify a user's identity.
5. Multi-Factor Authentication (MFA): Uses two or more verification methods, such as a password and OTP, for better security.  


Note App Architecture & Authentication Flow

1. Roles / Entities
- User (Verify / Identity)
- Note

2. User Registration (/register)
- Inputs: Name, Email, Password
- Process: Hashes password using bcrypt.hash (creates hashed password). Saves user data into the Database (DB).

3. User Login (/login)
- Inputs: Email, Password
- Process: 
  1. Compares hashed password using bcrypt.compare.
  2. Once verified, generates a token using jsonwebtoken.sign (creates a new token).
  3. Sends the JWT Token back to the client.

4. Authentication Middleware (Auth M/W)
- Function: Validates incoming requests to protected routes.
- Method: Uses jsonwebtoken.verify to check token validity.

5. Application Routes & Navigation Flow
- /home
- 1 /register
- 2 /login
- /dashboard
- /admin/data
