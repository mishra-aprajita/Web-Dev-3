Salt: A unique, random string added to a password before hashing to make
 passwords much harder to crack.

bcrypt.hash(): A method that takes a plain-text password and a salt to create a 
secure, one-way encrypted password string.

bcrypt.compare(): A method that checks if a user's plain-text password matches the 
encrypted hash stored in the database, returning true or false.

JWT (JSON Web Token) is a token used to verify a user's identity.
It securely transfers information between a client and a server.
It consists of three parts: Header, Payload, and Signature.
It is commonly used for authentication and authorization in web applications.

JWT has 3 parts:
1. Header: Specifies the token type and the algorithm used.
2. Payload: Contains user information, such as User ID and role.
3. Signature: Verifies that the token is authentic and its data has not been 
tampered with.

process.env is used in Node.js to access environment variables, such as MONGO_URL,
JWT_SECRET, and PORT, which store application configuration and sensitive information.

Node.js stores all available Environment Variables inside the process.env object,
allowing applications to access configuration values at runtime.
