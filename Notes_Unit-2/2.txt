# Express.js – 1-Minute Viva Notes

### Express.js

Express.js is a **Node.js framework** used to create **servers and APIs**.

* `app` → Express application
* `req` → Request received from the client
* `res` → Response sent from the server

### Request Data

* `req.body` → Data sent in the request body
* `req.params` → URL parameters, e.g. `/student/:id`
* `req.query` → Query parameters, e.g. `/student?id=3`

### Route

**HTTP Method + URL/Path = Route**

### HTTP Methods

* **GET** → Read data
* **POST** → Create data
* **PUT** → Completely update data
* **PATCH** → Partially update data
* **DELETE** → Delete data

### Request–Response Cycle

**Client → Request → Server → Processing → Response → Client**

* **Request** → Information sent by the client.
* **Response** → Information sent back by the server.

### Params vs Query

| Params                         | Query                                     |
| ------------------------------ | ----------------------------------------- |
| Part of the URL path           | Comes after `?`                           |
| Identifies a specific resource | Provides additional/filtering information |
| `/student/3`                   | `/student?id=3`                           |
| Usually uses `:id`             | Uses `key=value`                          |

**Easy trick:**
`/student/3` → Params
`/student?id=3` → Query

### Payload

**Payload** means the actual data sent by the client to the server.

Usually, in APIs, the payload is the data inside the **request body**.

Example:
`ID: 1, Name: Aprajita, Course: CSE`

Each consists of a **key-value pair**.

### Middleware

Middleware is a **function that works between the request and response cycle** and performs a specific task.

**Flow:**
Client → Request → Middleware → Route/Logic → Response → Client

Examples:

* Data parsing
* Authentication
* Authorization
* Logging
* Validation
* Error handling

`app.use()` → Used to register/use middleware.

### express.json()

`express.json()` is middleware used to **parse incoming JSON request data** so that the server can access the data in the request body.

**Viva:** Why do we use `express.json()`?
→ To parse incoming JSON data from the request body.

### JSON

**JSON = JavaScript Object Notation**

JSON is a **data interchange format**, not a JavaScript data type.

It is commonly used to **store and exchange structured data**.

JSON requires:

* Double quotes around keys
* Double quotes around string values

### JSON.parse() and JSON.stringify()

**JSON.parse()**
JSON string → JavaScript object

**JSON.stringify()**
JavaScript object → JSON string

**Easy trick:**
**Parse = JSON → JS**
**Stringify = JS → JSON**

### File System (fs)

The Node.js **File System (`fs`) module** is used to work with files.

* `fs.readFileSync()` → Reads a file
* `fs.writeFileSync()` → Writes/updates a file

### Array Methods

**push()** → Adds an element to an array.

**map()** → Processes each element and creates a new array. Often used for updating data.

**filter()** → Selects elements that satisfy a condition. It can be used to remove/delete an item by keeping all other elements.

### CRUD

| CRUD | Operation | HTTP Method |
| ---- | --------- | ----------- |
| C    | Create    | POST        |
| R    | Read      | GET         |
| U    | Update    | PUT / PATCH |
| D    | Delete    | DELETE      |

### Most Important Viva Answers

**Q. What is Express.js?**
A. Express.js is a Node.js framework used to build servers and APIs.

**Q. What is a route?**
A. A route is a combination of an HTTP method and a path that defines how a request is handled.

**Q. What is middleware?**
A. Middleware is a function that works during the request-response cycle and performs a specific task.

**Q. What is request body?**
A. It contains data sent by the client inside the request.

**Q. What are request parameters?**
A. They are dynamic values included in the URL path.

**Q. What are query parameters?**
A. They are parameters passed in the URL after `?`.

**Q. What is a payload?**
A. Payload is the actual data sent by the client to the server.

**Q. What is JSON?**
A. JSON stands for JavaScript Object Notation and is a format used to exchange structured data.

**Q. Is JSON a data type?**
A. No. JSON is a data interchange format.

**Q. PUT vs PATCH?**
A. PUT is generally used for a complete update or replacement, while PATCH is used for a partial update.

**Q. Why is middleware important?**
A. It allows us to perform tasks such as parsing, authentication, validation, and logging during the request-response cycle.

**Q. What are the five main HTTP methods?**
A. GET, POST, PUT, PATCH, and DELETE.
