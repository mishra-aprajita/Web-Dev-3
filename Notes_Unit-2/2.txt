1. Express.js
Express.js is a Node.js framework.
It is used to create servers and APIs.
It makes handling requests, responses, routes, and middleware easier.
2. Request–Response Cycle

Client → Request → Server → Processing → Response → Client

Request: Data/information sent by the client to the server.
Response: Data/information sent by the server back to the client.
The server receives the request, processes it, and sends an appropriate response.
3. Route

A route defines how the server should respond to a particular URL/path and HTTP method.

Example concept:

Method + Path = Route

Different routes can perform different operations such as reading, creating, updating, or deleting data.

4. Three Ways to Send/Access Data
A. Request Body
Contains data sent inside the request.
Accessed through request body.
Mainly used when sending larger/structured data.
Commonly used with POST, PUT, and PATCH.
Example: student details such as ID, name, course, etc.
B. Request Parameters
Used to identify a particular resource through the URL.
Written as a dynamic part of the route.
Example concept: /student/3
Here, 3 is the parameter value.
Accessed through request parameters.
C. Query Parameters
Used to send additional information through the URL.
Written after ?.
Example concept: /student?id=3
id=3 is a query parameter.
Multiple query parameters can be separated using &.
5. Params vs Query
Request Parameter	Query Parameter
Part of the URL path	Comes after ?
Used to identify a resource	Used to provide additional/filtering information
Example: /student/3	Example: /student?id=3
Usually represented by :id	Written as key=value
Easy trick:

/student/3 → Params

/student?id=3 → Query

6. Payload

Payload = actual data being sent by the client to the server.

Usually, when talking about APIs, payload refers to the data contained in the request body.

Example concept:

Student data:

ID → 1
Name → Aprajita
Course → CSE

Each key-value pair consists of:

Key : Value

So if an object contains ID, Name, and Course, it has 3 key-value pairs.

7. HTTP Methods
GET

Used to read/retrieve data.

POST

Used to create/add new data.

PUT

Used for complete update/replacement of existing data.

PATCH

Used for partial update of existing data.

DELETE

Used to delete data.

Remember:

GET → Read
POST → Create
PUT/PATCH → Update
DELETE → Delete

8. Middleware — VERY IMPORTANT 5 MARKS
Definition

Middleware is a function that sits between the request and response cycle and performs a specific task.

It can access the request and response objects and perform processing before the final response is sent.

Flow:

Request → Middleware → Server/Route Logic → Response

Examples of middleware tasks:
Parsing request data
Authentication
Authorization
Logging
Validation
Error handling
9. express.json() Concept

It is a type of middleware.

Its purpose is to process incoming JSON request data so that the server can access the data sent in the request body.

Viva answer:

Why do we need JSON middleware?

To parse incoming JSON data from the request body so that it can be accessed by the server.

10. Middleware — 5 Mark Answer

If the teacher asks "Explain Middleware", write:

Middleware is a function that executes during the request-response cycle. It sits between the client request and the server response. It can access the request and response objects and perform specific tasks such as parsing data, authentication, logging, validation, and error handling. Middleware helps process a request before it reaches the final route handler.

Diagram:

Client → Request → Middleware → Route/Logic → Response → Client

11. JSON

JSON = JavaScript Object Notation

JSON is a data format, not a JavaScript data type.
It is commonly used for storing and exchanging structured data.
JSON uses double quotes for keys and string values.
Important correction:

JSON is NOT a data type.

It is a data interchange format.

12. JavaScript vs JSON Quotes
JavaScript

JavaScript strings can use:

Single quotes
Double quotes
Backticks
JSON

JSON requires:

Double quotes for keys
Double quotes for string values
13. JSON Parse and Stringify
JSON.parse()

Converts:

JSON string → JavaScript object

JSON.stringify()

Converts:

JavaScript object → JSON string

Easy trick:

Parse = JSON → JS

Stringify = JS → JSON

14. File System

Node.js provides the File System (fs) module for working with files.

In your project it is used to:

Read student data from the JSON file.
Write updated student data back to the JSON file.
Two important operations:

Read file → readFileSync concept

Write file → writeFileSync concept

15. Array Methods Used
push()

Used to add an element to an array.

Used while creating a new student.

map()

Used to process each element and create a new array.

Used for updating student data.

filter()

Used to select elements based on a condition.

Used for deleting a student by keeping all students except the one matching the given ID.

16. CRUD

CRUD represents the four basic operations of an API:

CRUD	Operation	HTTP Method
C	Create	POST
R	Read	GET
U	Update	PUT / PATCH
D	Delete	DELETE
17. Most Important Viva Questions

Q. What is Express.js?
A. A Node.js framework used to build servers and APIs.

Q. What is a route?
A. A combination of an HTTP method and path that defines how a request is handled.

Q. What is middleware?
A. A function that operates between the request and response cycle.

Q. What is request body?
A. Data sent by the client inside the request.

Q. What are request parameters?
A. Dynamic values included as part of the URL path.

Q. What are query parameters?
A. Parameters passed in the URL after ?.

Q. What is payload?
A. The actual data sent by the client to the server.

Q. What is JSON?
A. JavaScript Object Notation, a format used to exchange/store structured data.

Q. Is JSON a data type?
A. No. JSON is a data format.

Q. What is the difference between PUT and PATCH?
A. PUT is generally used for complete replacement/update, while PATCH is used for partial updates.

Q. Why is middleware important?
A. It allows us to perform processing such as parsing, authentication, validation, and logging during the request-response cycle.

Q. What are the five main HTTP methods?
A. GET, POST, PUT, PATCH, and DELETE.
