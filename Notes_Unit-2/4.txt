# 1. Router

### What is a Router?

Router is used to organize and manage routes in an Express application.

### Why use Router?

* Keeps the code clean
* Routes can be organized into separate files
* Makes the application modular and maintainable

### What is Express Router?

It is like a mini Express application used specifically for handling routes.

### Main purpose of Router?

→ Route management and organization

### Role of `app.use()`?

→ It connects/mounts the Router with the main Express application.

### Viva one-liner:

Router is used to organize different routes in a clean and structured way.

---

# 2. Middleware

### What is Middleware?

Middleware is a function that works between the request and response cycle.

### Flow:

**Request → Middleware → Route Handler → Response**

### Main components of Middleware?

* Request
* Response
* Next

### What does `next()` do?

It passes control to the next middleware or handler.

### Viva one-liner:

Middleware processes a request before the final response is sent.

---

# 3. CORS

### Full form:

**Cross-Origin Resource Sharing**

### What is CORS?

CORS is a mechanism that allows a frontend and backend running on different origins 
to communicate through a browser.

### Example:

Frontend → Port 3000
Backend → Port 5000

**Different ports = different origins**

### Why is CORS needed?

Because of browser security rules, requests from different origins can be restricted.
 CORS allows appropriate access.

### Package for CORS?

→ `cors`

### Is CORS authentication?

→ No

### Does CORS secure the API?

→ Not by itself. CORS mainly controls browser-based cross-origin access.

### Viva one-liner:

CORS allows communication between frontend and backend when they are running on 
different origins.

---

# 4. Multer

### What is Multer?

Multer is a middleware for handling file uploads in Node.js and Express.

### What type of data does Multer handle?

→ `multipart/form-data`

### Where is Multer used?

* Image upload
* PDF upload
* Documents
* Other files

### Where can uploaded file information be found?

→ `req.file` for a single file
→ `req.files` for multiple files

---

# 5. Important Multer Methods

### `single`

→ Used for uploading one file.

### `array`

→ Used for uploading multiple files.

### `fields`

→ Used to handle different file fields.

---

# Viva:

### Difference between single and multiple file upload?

Single is used for a single file, while multiple files can be handled using `array`
 or appropriate multi-field handling.

---

# Router vs CORS vs Multer

| Topic      | Main Work                                              |
| ---------- | ------------------------------------------------------ |
| Router     | Organizes/manages routes                               |
| Middleware | Performs processing in the request-response cycle      |
| CORS       | Allows browser communication between different origins |
| Multer     | Handles file uploads                                   |

### Super-short revision

**Router → Routes**
**Middleware → Request processing**
**CORS → Different origins**
**Multer → File upload**
**multipart/form-data → File upload data type**
